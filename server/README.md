# Lifea backend

Friends, presence, direct messages, party invites, cosmetics and news for LifeaLauncher and the `lifea-core` mod.

- **Auth:** the launcher sends the player's Minecraft access token once; the server checks it against
  `api.minecraftservices.com/minecraft/profile` and returns its own 12-hour JWT. Mojang tokens are never stored.
  Offline accounts are rejected unless `ALLOW_OFFLINE=1` (development only — offline names can be spoofed).
- **Storage:** PostgreSQL when `DATABASE_URL` is set, otherwise SQLite (`node:sqlite`) in `data/lifea.db`.
- **Realtime:** `GET /realtime?token=…` WebSocket for presence, DMs, emotes (shared with players on the same server)
  and party invites.

## Run

```bash
npm install
JWT_SECRET=$(openssl rand -hex 32) PUBLIC_URL=http://localhost:8787 npm run dev
# or
docker build -t lifea-server . && docker run -p 8787:8787 -e JWT_SECRET=... -e PUBLIC_URL=https://api.example.com lifea-server
```

Then set **Settings → Advanced → Backend URL** in the launcher (or build it with `LIFEA_BACKEND_URL`).

| Variable | Default | Meaning |
|---|---|---|
| `JWT_SECRET` | — (required, ≥ 32 chars) | Signs session tokens |
| `PUBLIC_URL` | `http://localhost:PORT` | Base URL used in cosmetic texture links |
| `PORT` / `HOST` | `8787` / `0.0.0.0` | Listen address |
| `DATABASE_URL` | — | PostgreSQL connection string |
| `SQLITE_FILE` | `data/lifea.db` | SQLite file when no Postgres |
| `ALLOW_OFFLINE` | — | `1` to accept offline accounts (dev only) |

## API

| Method | Path | Auth | |
|---|---|---|---|
| POST | `/auth/minecraft` | — | `{ accessToken }` → `{ token, uuid, username }` |
| POST | `/auth/offline` | — | dev only |
| GET | `/friends` | JWT | friends + live presence |
| GET/POST | `/friends/requests` | JWT | list / send `{ username }` |
| POST | `/friends/requests/:id/accept\|decline` | JWT | |
| DELETE | `/friends/:uuid` | JWT | |
| GET/POST | `/messages/:uuid` | JWT | history / send `{ body }` (friends only) |
| GET | `/cosmetics/catalog` | — | |
| GET/PUT | `/me/cosmetics` | JWT | `{ type, id \| null }` |
| POST | `/cosmetics/lookup` | — | `{ uuids: [...] }` (≤ 100) → equipped textures, used by lifea-core |
| GET | `/news`, `/featured-servers`, `/health` | — | |

Cosmetic textures in `assets/cosmetics` are original art generated by `scripts/gen_cosmetics.py`.
